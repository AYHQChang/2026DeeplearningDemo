# MLP 实验快速上手与练习指南

## 1. 本实验要完成什么

本实验使用月牙、同心圆和三分类螺旋数据，观察 MLP 如何形成二维决策边界，并通过受控实验比较激活函数、损失函数、优化器、网络深度、网络宽度和 Dropout。

完成后应能够：

1. 说明输入、标签和 logits 的张量形状；
2. 根据决策边界、loss、accuracy 和 gradient norm 判断训练现象；
3. 一次只替换一个组件，避免把多个因素混在同一结论中；
4. 修改已有配置，并能在核心代码中加入一个新组件；
5. 用实验记录说明“改了什么、看到了什么、能够得到什么结论”。

## 2. 五分钟开始

### 第一步：打开 Notebook

打开 `mlp_lab.ipynb`，选择课程使用的 Python 内核。

### 第二步：选择设备

Notebook 顶部只需要修改一行：

```python
DEVICE = "cpu"   # CPU
DEVICE = "cuda"  # NVIDIA GPU
```

两种设备共用模型、训练和绘图代码，不需要复制两套项目。

### 第三步：完整执行一次

执行 `Restart Kernel and Run All Cells`。默认配置可以直接运行；确认数据图、基线结果、组件对比和练习结果全部出现。

### 第四步：进入练习区

先完成“配置替换”，再根据进度选择“新增组件”“修改模型结构”或“参数预算挑战”。每次实验只改变一个目标变量，并立即填写记录。

## 3. 修改地图

| 目标 | 修改位置 | 建议改动量 | 难度 |
|---|---|---:|---|
| 更换已有激活函数、优化器、学习率或 Dropout | Notebook 的“配置替换”代码单元格 | 1–5 行 | 入门 |
| 调整隐藏层深度和宽度 | Notebook 中的 `practice_hidden_sizes` | 1 行 | 入门 |
| 增加 LeakyReLU 或 ELU | `core.py` 的 `_activation()` | 1 行 | 基础 |
| 增加 RMSprop | `core.py` 的 `validate_config()` 与 `_make_optimizer()` | 2–3 行 | 基础 |
| 修改 Linear、Activation、Dropout 的排列 | `core.py` 的 `MLP` 类 | 2–5 行 | 进阶 |
| 增加新的损失方案 | `core.py` 的 `_classification_loss()` | 2–5 行 | 进阶 |

`core.py` 已用“可修改组件区开始/结束”标出以上函数。数据生成、日志和绘图不属于首次修改范围。

只在 Notebook 中运行新组件时，无需修改命令行参数；如果还要通过 `demo.py` 选择新组件，再同步更新对应参数的 `choices`。

## 4. 分级练习

### A. 配置替换

在 Notebook 的练习代码单元格中，从以下项目选择一个：

- `relu`、`tanh`、`sigmoid`；
- `sgd`、`momentum`、`adam`；
- 隐藏层宽度与层数；
- `dropout`；
- 学习率。

要求：恢复基线后再开始下一次实验，每次只修改一个变量。

### B. 新增组件

任选一个任务：

1. 在 `_activation()` 的字典中增加 `"leaky_relu": nn.LeakyReLU`；
2. 在 `validate_config()` 和 `_make_optimizer()` 中增加 `rmsprop`；
3. 为新增组件设置一个合理的默认参数，并与最接近的已有组件进行对照。

新增后先运行 `python test_mlp_smoke.py`，再回到 Notebook 进行实验。

### C. 修改模型结构

从 `MLP` 类开始，尝试调整隐藏层组件顺序，或增加 `BatchNorm1d`。修改前先写出预期的张量形状，修改后打印模型并核对参数量。

如果模型不能运行，优先检查：

- `Linear` 的输入维度是否等于上一层输出维度；
- 激活层和 Dropout 是否只放在隐藏层；
- 输出层是否仍然直接产生 raw logits；
- `CrossEntropyLoss` 前是否错误地增加了 Softmax。

### D. 参数预算挑战

在三分类螺旋数据上，使参数量不超过 2,000，并尽量超过默认基线。先完成单变量实验，再允许组合多个设置。

建议至少使用三个不同的 `seed` 复核最终配置。不要只报告其中最高的一次结果，应同时说明结果是否稳定。

每完成一次实验，复制并填写一行：

| 1 |  |  | 42 |  |  |  |  |  |
| 2 |  |  | 42 |  |  |  |  |  |
| 3 |  |  | 42 |  |  |  |  |  |

结论建议使用下面的句式：

> 本次只修改了 ______。从 ______ 图可以看到 ______。在当前数据、随机种子和训练轮数下，结果支持 / 不支持 ______。

避免写成“某组件永远更好”。结论只适用于当前实验条件，换数据、学习率或随机种子后可能改变。

## 6. 完成标准

一次完整练习至少包含：

1. 一个明确的运行配置；
2. 一条只改变一个变量的对照；
3. 一项数值证据和一项图形证据；
4. 一段说明结论边界的文字；
5. 修改核心组件时，通过 `test_mlp_smoke.py`。

需要查询全部命令行参数、日志文件和图形含义时，再打开 `使用手册.md`。
