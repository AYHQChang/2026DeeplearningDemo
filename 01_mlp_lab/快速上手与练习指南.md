# MLP 实验快速上手与练习指南

## 1. 先运行，再理解

第一次进入实验时，不要求阅读训练循环或绘图代码。按顺序打开 6 份 notebook，
每完成一步都会得到图片或数值结果。

```text
00_一键体验
    ↓
01_认识数据与张量
    ↓
02_训练规则与超参数
    ↓
03_训练第一个MLP
    ↓
04_组件对比实验
    ↓
05_自主修改练习
```

## 2. 五分钟开始

1. 打开 `00_一键体验.ipynb`；
2. 选择课程使用的 Python 内核；
3. 点击 `Run All`；
4. 等待结果表和两张图片出现；
5. 先观察结果，不需要立即理解隐藏的准备单元。

默认设备为：

```python
device="auto"
```

`auto` 会在 CUDA 可用时使用 GPU，否则使用 CPU。显式选择设备时可填写：

```python
device="cpu"
device="cuda"
```

## 3. 每份 notebook 要完成什么

### 00｜一键体验

运行一行 `quick_demo(...)`，得到：

- 训练阶段决策边界；
- 最终边界与误判点；
- Loss 曲线；
- 训练集与测试集 Accuracy；
- Gradient norm；
- 参数量与训练时间。

### 01｜认识数据与张量

查看月牙、同心圆和螺旋三种数据，并把图片、公式和代码对应起来：

- 数据集写作 $\mathcal{D}=\{(\mathbf{x}_i,y_i)\}_{i=1}^{N}$；
- `X` 的形状为 `[样本数, 2]`；
- `y` 的形状为 `[样本数]`；
- 认识 Tensor 的 `ndim`、`shape`、`dtype` 和 `device`；
- 训练集与测试集分开；
- 标准化参数只从训练集估计。

### 02｜训练规则与超参数

用 12 个样本的图片理解 Batch、Step 和 Epoch，再通过二次函数观察不同学习率：

- 一个 Batch 触发一次参数更新；
- 全部训练样本使用一遍称为一个 Epoch；
- Batch size 决定一次使用多少样本；
- Loss 衡量当前预测误差；
- Gradient 给出参数的更新方向；
- Learning rate 控制每一步走多远。

最后运行一次真实的 PyTorch 更新：`zero_grad → forward → loss → backward → step`。

### 03｜训练第一个 MLP

只训练一个模型，按以下顺序读图：

1. 决策边界是否逐渐稳定；
2. Loss 是否总体下降；
3. 测试集 Accuracy 是否跟随训练集变化；
4. 误判点主要出现在哪里；
5. 梯度是否过大、过小或剧烈震荡。

### 04｜组件对比实验

每次只替换一个组件。默认提供激活函数与优化器两组对比，每列对应一种配置。
不能只根据最高 Accuracy 下结论，还要结合边界、Loss、泛化差距和梯度。

### 05｜自主修改练习

参数区只需要修改一行：

```python
hidden_sizes = (16, 16)
activation = "tanh"
optimizer = "adam"
dropout = 0.0
learning_rate = 0.02
```

每次只改一个变量，运行后立即比较基线图和修改后的图。

## 4. 从参数修改进入代码修改

完成 6 份 notebook 后，再阅读 `mlp_lab/model.py`。该文件只包含激活函数映射和
MLP 结构，适合完成以下练习：

| 目标 | 修改位置 | 建议改动量 |
|---|---|---:|
| 增加 LeakyReLU 或 ELU | `mlp_lab/model.py` 的 `_activation()` | 1 行 |
| 调整 Linear、Activation、Dropout 顺序 | `mlp_lab/model.py` 的 `MLP` | 2–5 行 |
| 增加 RMSprop | `mlp_lab/engine.py` 的验证与优化器函数 | 2–3 行 |
| 增加新的损失方案 | `mlp_lab/engine.py` 的损失函数 | 2–5 行 |

数据生成、日志和绘图代码不属于首次修改范围。

## 6. 完成标准

一次完整练习至少包含：

1. 一次成功运行和对应图片；
2. 一条只改变一个变量的对照；
3. 一项数值证据和一项图形证据；
4. 一段说明结论边界的文字；
5. 修改模型代码时，通过 `python test_mlp_smoke.py`。

需要查询全部命令行参数、日志文件和图形含义时，再打开 `使用手册.md`。
