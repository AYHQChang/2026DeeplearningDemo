# Windows 笔记本安装与配置 Miniconda

## 1. 这份教程适用于谁

这份教程用于个人 Windows 笔记本。实验室电脑带有还原功能，课堂上直接使用 Linux 服务器环境，不在实验室电脑重复安装 Miniconda。

Miniconda 是 Conda 的轻量安装版本。Conda 可以为不同项目建立相互隔离的 Python 环境，避免所有项目共用一套 Python 和软件包。

本课程统一创建：

```text
环境名称：dl2026
Python 版本：3.11
```

---

## 2. 安装前先检查

打开 Windows PowerShell，运行：

```powershell
conda --version
```

如果能看到类似：

```text
conda 25.x.x
```

说明电脑已经安装了 Anaconda 或 Miniconda。不要重复安装，直接跳到第 7 节创建课程环境。

如果提示无法识别 `conda`，再到 Windows 开始菜单搜索：

```text
Anaconda Prompt
Miniconda Prompt
```

如果其中一个可以打开，并且能运行 `conda --version`，说明 Conda 已经安装，只是普通 PowerShell 尚未初始化。跳到第 6 节。

只有两处都找不到时，才开始安装。

---

## 3. 准备安装位置

使用班长发放的 Windows 64 位 Miniconda 图形安装程序，本课程发放的文件名是：

```text
Miniconda3-latest-Windows-x86_64.exe
```

`x86_64` 表示普通 Intel 或 AMD 64 位 Windows 笔记本使用的版本。

安装目录必须尽量简单，只使用英文字母、数字和英文符号。推荐：

```text
D:\miniconda3
```

如果没有 D 盘，可以使用：

```text
C:\miniconda3
```

不推荐：

```text
C:\Program Files\Miniconda3
D:\张三\深度学习\Miniconda3
```

原因是空格、中文或特殊字符可能让部分开源工具出现路径兼容问题。

---

## 4. 按安装向导操作

双击 Miniconda 安装程序，然后依次操作。

### 第 1 页：Welcome

点击 `Next`。

### 第 2 页：License Agreement

阅读许可协议，点击 `I Agree`。

### 第 3 页：Installation Type

选择：

```text
Just Me (recommended)
```

不要选择 `All Users`。个人安装通常不需要管理员权限，也不会影响电脑上的其他账号。

### 第 4 页：Choose Install Location

填写前面准备的纯英文路径，例如：

```text
D:\miniconda3
```

确认路径没有中文和多余空格，再点击 `Next`。

### 第 5 页：Advanced Installation Options

按下面方式选择：

| 选项 | 本课程建议 | 原因 |
|---|---|---|
| Create shortcuts | 勾选 | 保留 Miniconda Prompt 快捷入口 |
| Add Miniconda3 to my PATH environment variable | **不勾选** | 永久加入可能干扰其他 Python 软件 |
| Register Miniconda3 as my default Python | 可以保留默认 | 便于 VS Code 发现；之后仍要手动选择 `dl2026` |
| Clear package cache upon completion | 保留默认 | 不影响课程使用 |

特别注意：不要因为后面要“设置环境变量”，就在这里勾选 `Add Miniconda3 to my PATH`。本课程使用更安全的 `conda init powershell`。

### 第 6 页：Install

点击 `Install`，等待安装完成。不要在安装过程中强制关闭窗口。

完成后点击 `Next` 和 `Finish`。

---

## 5. 第一次验证安装程序是否完成

打开 Windows 开始菜单，搜索并打开：

```text
Miniconda Prompt
```

有些版本显示为 `Anaconda Prompt`，也可以使用。

运行：

```bat
conda --version
conda info --base
conda list
```

正确结果应满足：

1. `conda --version` 显示版本号；
2. `conda info --base` 显示刚才选择的目录，例如 `D:\miniconda3`；
3. `conda list` 能列出 base 环境中的软件包。

如果这三项都正常，说明 Miniconda 软件本身已经安装成功。

## 6. 让普通 PowerShell 能使用 Conda

### 先理解环境变量

Windows 的 `PATH` 是一组“到哪里寻找命令”的目录。如果把很多 Python 目录永久放进 `PATH`，不同 Python 版本可能互相覆盖。

本课程采用下面的方式：

```text
不把整个 Miniconda 永久塞进系统 PATH
        ↓
使用 conda init 初始化 PowerShell
        ↓
执行 conda activate 时，由 Conda 临时调整当前终端的 PATH
```

### 初始化 PowerShell

在 `Miniconda Prompt` 中执行一次：

```bat
conda init powershell
```

看到修改 PowerShell 配置的提示后：

1. 关闭所有 PowerShell；
2. 关闭所有 VS Code 窗口；
3. 重新打开 PowerShell。

然后运行：

```powershell
Get-Command conda
conda --version
conda info --base
```

只要这三条命令成功，普通 PowerShell 的 Conda 初始化就完成了。

### 如果 Miniconda Prompt 中也无法直接执行 `conda init`

使用安装目录中的完整路径。安装在 D 盘时：

```powershell
& "D:\miniconda3\Scripts\conda.exe" init powershell
```

安装在 C 盘时：

```powershell
& "C:\miniconda3\Scripts\conda.exe" init powershell
```

执行后仍然要关闭全部 PowerShell 和 VS Code，再重新打开。

### 不推荐手工添加永久 PATH

不要把下面这些目录全部手工加入系统 `PATH`：

```text
D:\miniconda3
D:\miniconda3\Scripts
D:\miniconda3\Library\bin
```

它们可能让其他程序在没有激活 Conda 环境时也使用 Conda 的 Python 或动态库。

如果学校安全策略阻止 PowerShell 加载 Conda 初始化脚本，不要修改全局执行策略。直接使用 `Miniconda Prompt` 完成课程操作。

## 7. 创建课程环境

在已经能识别 Conda 的 PowerShell 或 `Miniconda Prompt` 中执行：

```powershell
conda create -n dl2026 python=3.11 pip -y
```

解释：

- `conda create`：创建新环境；
- `-n dl2026`：环境名称是 `dl2026`；
- `python=3.11`：安装 Python 3.11；
- `pip`：同时准备 Python 包安装工具；
- `-y`：自动确认安装计划。

创建过程需要访问软件源。网络较慢时先等待，不要连续重复执行同一命令。

创建完成后激活环境：

```powershell
conda activate dl2026
```

命令行左侧通常会出现：

```text
(dl2026)
```

## 8. 检查环境变量是否正确

激活 `dl2026` 后运行：

```powershell
python --version
where.exe python
python -c "import sys; print(sys.executable)"
$env:CONDA_PREFIX
```

安装成功应满足：

1. `python --version` 显示 `Python 3.11.x`；
2. `where.exe python` 第一条路径位于 `...\envs\dl2026\python.exe`；
3. `sys.executable` 也指向 `dl2026`；
4. `$env:CONDA_PREFIX` 结尾是 `envs\dl2026`。

可以观察 Conda 激活后放到当前终端前面的 PATH：

```powershell
($env:Path -split ';') | Select-Object -First 8
```

前几项通常包含 `dl2026` 环境目录。这些修改只对当前终端会话生效。执行：

```powershell
conda deactivate
```

后，Conda 会撤回该环境对当前终端 `PATH` 的调整。

不要为本课程手工创建 `PYTHONPATH`、`PYTHONHOME`、`CUDA_HOME` 或 `CUDA_PATH`。这些变量不是安装 Miniconda 的必要条件，错误设置反而会干扰 Python。

## 9. 在 VS Code 中选择课程环境

1. 打开课程专用 VS Code 1.98.2；
2. 按 `Ctrl + Shift + P`；
3. 选择 `Python: Select Interpreter`；
4. 选择名称包含 `dl2026`、路径位于 `envs\dl2026` 的 Python；
5. 打开 Notebook 时，再点击右上角内核名称，选择同一个 `dl2026`。

解释器和 Notebook 内核是两个入口，需要分别检查。

在 VS Code 新终端中运行：

```powershell
conda activate dl2026
python --version
python -c "import sys; print(sys.executable)"
```

结果仍然应指向 `dl2026`。

## 11. 常见问题

### `conda` 不是内部或外部命令

先打开 `Miniconda Prompt` 验证。如果那里正常，执行：

```bat
conda init powershell
```

然后关闭并重新打开全部终端。

### `python` 打开 Microsoft Store

说明当前没有激活 `dl2026`，或者 WindowsApps 排在前面。先执行：

```powershell
conda activate dl2026
where.exe python
```

不要在 Microsoft Store 中临时再装一套 Python。

### 安装目录包含中文

如果尚未创建环境，建议卸载后安装到 `D:\miniconda3` 或 `C:\miniconda3`。不要简单移动已经安装好的 Miniconda 文件夹。

### PowerShell 提示无法加载配置文件

不要为课堂安装全局关闭执行策略。改用 `Miniconda Prompt`，并把完整报错发给教师。

### 已有 Anaconda 或 Miniconda

只要现有 `conda` 能正常创建 Python 3.11 环境，就不需要卸载或重复安装。课程环境用独立名称 `dl2026` 即可。
