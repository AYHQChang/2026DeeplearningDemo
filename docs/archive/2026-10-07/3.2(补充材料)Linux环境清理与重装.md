# Linux 课程环境清理与重装

适用情况：安装时报 `No space left on device`，或者误建了多个 Conda 环境，需要删除多余环境、重建课程环境。

所有命令都在 **VS Code 连接服务器后的终端** 中执行，每次执行一个代码块。先保存 Notebook，并停止正在运行的内核和训练程序。

- **只是安装时空间不足：**执行第一部分，再到第三部分继续安装。
- **需要删除多余环境或重建：**执行第二部分；重建后到第三部分安装。
- 课程使用 **Python 3.11、环境名 dl2026、PyTorch 2.5.1 CUDA 11.8 版**。`base` 是 Conda 的基础环境，保留它。

## 一 清理 pip 下载缓存

### 1 激活课程环境并查看缓存

```bash
conda activate dl2026
python -m pip cache info
```

查看输出中的缓存大小。反复安装不同版本可能留下缓存；`Using cached` 表示正在复用缓存，不代表每次都新增一份。

如果 `dl2026` 不存在，要先重建，请转到第二部分。若提示 `conda: command not found`，先运行：

```bash
source "$HOME/miniconda3/etc/profile.d/conda.sh"
```

### 2 清理缓存

```bash
python -m pip cache purge
```

这会清理当前账号配置的 pip 缓存，不会卸载已安装的包，也不会删除课程代码和作业。后续需要的包会重新下载。

### 3 查看剩余空间

```bash
df -h "$CONDA_PREFIX"
```

看 `Avail`（剩余空间）和 `Use%`（使用比例）。CUDA 版 PyTorch 连同依赖、解压文件需要数 GB 空间，仅腾出几百 MB 通常不够。

如果空间足够，直接到第三部分继续安装，**不用删除或重新创建 dl2026**。

若清理后仍报空间不足，运行下面的只读检查，把结果发给老师：

```bash
python -c "import tempfile; print('临时目录：', tempfile.gettempdir())"
df -h "$CONDA_PREFIX" "$(python -c 'import tempfile; print(tempfile.gettempdir())')"
df -i "$CONDA_PREFIX" "$(python -c 'import tempfile; print(tempfile.gettempdir())')"
quota -s
```

`quota` 若提示命令不存在，保留其他输出即可。问题也可能出在临时分区、文件数量上限或账号配额；反复重试安装不会自动释放这些空间。

## 二 删除多余环境或重建课程环境

### 1 查看已有环境

```bash
conda env list
```

输出示例：

```text
base                    /自己的路径/miniconda3
dl2026                * /自己的路径/miniconda3/envs/dl2026
dl2026_old              /自己的路径/miniconda3/envs/dl2026_old
```

`*` 表示当前激活的环境。**base 加 dl2026 是正常的两个环境，不代表重复安装。**只有确认不再使用的额外环境才需要删除，并核对右侧路径属于自己的账号。

### 2 退出当前课程环境

```bash
conda deactivate
conda env list
```

确认要删除的环境旁边没有 `*`。如果仍有，继续执行一次 `conda deactivate` 并检查。

### 3 按需要删除

**只删除多余环境：**例如确认 `dl2026_old` 是误建的环境，执行：

```bash
conda env remove -n dl2026_old
```

把示例中的 `dl2026_old` 换成列表中实际要删除的名称。出现确认提示时，检查将删除的环境路径，确认无误后输入 `y`。有多个多余环境时，逐个确认、逐个删除。

**需要彻底重建 dl2026：**确认不再保留其中安装的包后，执行：

```bash
conda env remove -n dl2026
```

删除环境会删除该环境目录中的 Python 和已安装软件；环境目录之外的课程项目与作业不受影响。如果曾把作业存进环境目录，先移到项目文件夹。不要删除 `base`，也不要直接删除整个 `miniconda3` 文件夹。

删除后检查：

```bash
conda env list
```

### 4 仅在 dl2026 已不存在时重建

```bash
conda create -n dl2026 python=3.11 pip -y
conda activate dl2026
python --version
```

应显示 `Python 3.11.x`。如果只是删除了其他多余环境、保留了原来的 `dl2026`，只需运行 `conda activate dl2026`，不用再执行 `conda create`。

删除环境不等于清空 pip 缓存。若仍需腾空间，可在激活环境后执行第一部分的缓存清理命令。

## 三 安装课程依赖与 PyTorch

### 1 确认当前环境和项目位置

```bash
conda activate dl2026
python -c "import sys; print(sys.executable)"
pwd
ls requirements.txt
```

Python 路径应包含 `envs/dl2026/`。当前目录必须是课程项目根目录，能看到 `requirements.txt`、`check_environment.py` 和 `01_mlp_lab` 等文件。

如果找不到 `requirements.txt`，在 VS Code 中打开课程项目根文件夹，再新建终端并激活 `dl2026`。也可以用 `cd` 进入项目；例如项目确实在下列位置时：

```bash
cd "$HOME/courses/Deeplearning2026"
```

**路径不同就换成自己的实际项目路径。**不要在 `01_mlp_lab` 或 `02_cnn_lab` 子目录中执行下面的依赖安装命令。

### 2 先装课程通用依赖

```bash
python -m pip install --no-cache-dir --only-binary=:all: -r requirements.txt
```

课程依赖已固定适合服务器的版本，请保留此安装顺序。如果命令报错，先把完整报错发给老师，不要继续下一步。

### 3 再装 PyTorch

```bash
python -m pip install --no-cache-dir torch==2.5.1 --index-url https://download.pytorch.org/whl/cu118
```

`--no-cache-dir` 避免本次安装额外保存 pip 下载缓存，但安装目录和临时目录仍需要足够空间。已安装且满足要求的包通常会显示 `Requirement already satisfied`，这是正常提示。

### 4 检查结果

```bash
python -m pip check
python -c "import torch; print('PyTorch:', torch.__version__); print('CUDA runtime:', torch.version.cuda); print('CUDA available:', torch.cuda.is_available())"
python check_environment.py
```

PyTorch 版本应显示 `2.5.1+cu118`，CUDA runtime 应显示 `11.8`。若在课程 GPU 服务器上 `CUDA available` 为 `False`，把输出发给老师检查。

## 四 回到 Notebook

1. 在 VS Code 中打开本次实验文件夹，例如 `01_mlp_lab` 或 `02_cnn_lab`。
2. 打开 Notebook，点击右上角的内核名称，重新选择 **dl2026** 对应的 Python 环境。
3. 重建环境后若列表未刷新，关闭并重新打开 VS Code 的服务器窗口。
4. 从第一个单元格开始运行；不要沿用删除前仍在运行的旧内核。

可以先在 Notebook 中运行下面一行，确认实际使用的 Python 路径包含 `envs/dl2026/`：

```python
import sys
print(sys.executable)
```

以后登录只需激活环境，不要每次创建：

```bash
conda activate dl2026
```

首次安装 Miniconda 的完整步骤见 [Linux 服务器 Conda 与 PyTorch 安装指南](./3.Linux服务器Conda与PyTorch安装.md)。

命令依据：[pip 缓存说明](https://pip.pypa.io/en/stable/topics/caching/)；[Conda 删除环境说明](https://docs.conda.io/projects/conda/en/stable/commands/env/remove.html)。
