# 图片序列化分类：文本主线之后的选做扩展

入口：[01_服饰图片分层实验.ipynb](01_服饰图片分层实验.ipynb)。从仓库根目录、`03_rnn_lab` 或本目录启动均可，不需 `pip install rnn_lab`。原 `03_rnn_lab/05_自主修改练习.ipynb` 已迁入此处，只有这一份维护入口。

本页在第一个TODO前提供6×8编号矩阵的逐行/分块空间图和分层任务地图，已保留可展开的预览。先圈出一个时间步包含的原图位置，再补转换代码。人工矩阵只解释坐标，实际训练继续使用原Fashion数据；预览不包含作业答案或学生训练成绩。课堂优先从[文本00](../06_text_classification/00_情感分类体验.ipynb)开始。

图片不是自然时间序列：逐行与分块顺序由我们规定。本实验不预测未来图片，也不能证明 RNN 比 CNN 更适合普通图片分类。目的是解释输入组织怎样改变 T、F、参数量和状态行为。课堂真实应用主线是[中文评论情感分类](../06_text_classification/README.md)；课后一周图片、文本任选一条，基础可独立提交，不要求做完两套工程。

| 挑战 | E：逐行/手写普通RNN/last；`RUN_MANUAL` | 只依赖A；共享递推TODO与TODO 8分类连接；不依赖B/C/D |

所有扩展默认关闭。TODO未完成时在明确位置停止，不会自动填答案；只完成基础的学生不必实现mean、分块或手写递推。提高C与进阶D互不依赖。E限定单层、单向、tanh、显式时间循环，使用自动求导；在[共享支架](../rnn_lab/manual_rnn.py)完成一份核心后，可复用于图片与文本。先同权重核对每步输出、最终状态与分类logits，再做小训练；不要求手写LSTM/GRU或优化器。

A/B比较循环单元；B/C比较状态读出；B/D比较组织方式；A/E比较实现正确性。默认4×4分块将`[B,1,28,28]`变为`[B,49,16]`；块行优先、块内行优先。探针独立读取原图坐标，不能仅凭shape或正逆相抵证明正确。分块同时改变T/F及输入权重，成绩差异不能全部解释成记忆能力。参数量、耗时与验证指标一起记录，没有准确率分档或自动评分。

## 记录、测试和一周安排

训练/选型默认只用train/val。验证集完成方案选择后，在最终测试单元显式开启测试，只评价固定模型；未测试的CSV字段留空。模型状态改变后，首次测试缓存不得复用于新模型。截然不同的多轮探索均保留，不只留下最好成绩。

新输出在`03_rnn_lab/outputs/05_image_classification/时间_uuid/`，包含CSV、输入图、状态图、验证比较和错例；历史输出不移动、不删除。**历史05输出中的旧B/C/D编号不适用本次新的A–E解释。**默认CPU单线程、H=32、8轮是起点；实际性能取决于环境与实现，不承诺准确率或未经测量的耗时。单层循环层的层间dropout不生效。

建议先用2–3天完成A及报告，再用余下时间任选B/C、D或E深入。提交可运行Notebook、CSV与关键图，并解释空间坐标、B/T/F/H/K、验证错例和对照因素。挑战另交逐步数值核对、一个自己定位的错误，以及每步清零状态与共享权重的解释；梯度一致性选做。具体截止时间与提交形式按课堂要求。

教师验证用临时答案只保存在gitignored输出或临时目录，学生Notebook和公开测试保留关键TODO。CPU验证环境与实际图以[实验室README](../README.md)的本轮记录为准。
