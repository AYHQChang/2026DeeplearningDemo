# RNN 延迟回忆实验室

本实验室用一个可视化的“秘密符号”任务认识循环神经网络（Recurrent Neural Network，RNN）：序列开头给出红、绿或蓝中的一个秘密符号，中间加入与答案无关的噪声，末尾出现查询标记，模型需要回答最开始的符号。

数据由本地代码生成，不需要联网下载。模型很小，核心实验默认使用 CPU，适合共享服务器上的同步练习。

## 学习目标

完成六份 Notebook 后，应当能够：

- 读懂序列张量 `[Batch, Time, Feature]`；
- 解释隐藏状态 `h_t` 怎样沿时间步传递信息；
- 使用 PyTorch 训练一个序列分类模型；
- 在相同数据和超参数下比较 Vanilla RNN、LSTM 与 GRU；
- 区分长期依赖、梯度消失与梯度爆炸；
- 一次只修改一个变量，并用图表支持结论。

## 数据长什么样

输入采用：

```text
[Batch, Time, Feature]
```

每条序列包含：

```text
秘密符号 → 随机干扰 → 随机干扰 → …… → 查询标记
```

前三个 Feature 通道表示三类秘密符号，中间通道保存与标签无关的随机噪声，最后一个通道表示“现在请回答”。标签是 `0、1、2` 中的一个类别编号。

## 共享服务器约定

- 默认 `DEVICE = "cpu"`，每个进程只使用一个 CPU 线程。
- 只有获得课堂分配后，才把设备改为 `cuda:x`；`x` 必须替换成指定 GPU 编号。
- 不使用自动 GPU 选择，避免多人集中到同一块 GPU。
- `DataLoader` 不创建额外工作进程，核心实验不联网下载数据。
- `04` 的 `FAST_MODE = True` 是课堂默认值；完整对比应由教师统一安排或分批运行。

## 怎样修改实验

先运行基线，再只修改一个变量，例如：

- `sequence_length`：需要记忆多久；
- `cell_type`：`rnn`、`lstm` 或 `gru`；
- `hidden_size`：隐藏状态能保存多少维信息；
- `learning_rate`：每次参数更新的步长；
- `gradient_clip`：是否限制过大的梯度。

一次结果只对应当前数据、随机种子和超参数。不要因为一次 Accuracy 更高，就写成“某种模型永远更好”。
