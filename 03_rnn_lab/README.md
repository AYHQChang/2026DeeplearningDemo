## 先读懂每一个轴

默认单向、`batch_first=True` 的模型遵循：

```text
输入                         [B,T,F]
某一个时间步的输入           [B,F]
循环层顶层的全部输出         [B,T,H]
全部循环层的最终隐藏状态 h_n [L,B,H]
最后时刻读出的分类特征       [B,H]
分类分数 logits / 类别概率   [B,K]
argmax 类别编号              [B]
```

`B` 是批量大小，`T` 是时间步数，`F` 是每步输入特征数，`H` 是隐藏状态特征数，`L` 是堆叠的循环层数，`K` 是类别数。三维张量“有三个轴”，不是“每个轴都等于 3”。时间步之间共享同一层权重，层数不等于时间步数；`batch_first` 不改变 `h_n` 的轴顺序。

LSTM 还返回 `[L,B,H]` 的细胞状态 `c_n`；`h` 与 `c` 不相同，`c` 不要求落在 `[-1,1]` 内。softmax 将分类分数转换成概率，argmax 取最大分数的类别；训练交叉熵直接接收 logits。

02 的小矩阵权重由人设置，用于手算；03/04 的轨迹来自模型真实前向。观察工具在临时 eval 模式下核对逐时刻重放，保留原模块训练状态和已有梯度，不更新 BatchNorm 统计量。状态图标明真实尺寸、显示单元数和颜色范围；LSTM 的 h/c 使用共享色阶，跨模型比较时仍应检查色条。热力图和输入梯度是描述性证据，不能直接证明某个单元“理解了某类图片”。

## 可以修改什么

| 参数 | 修改位置与含义 |
|---|---|
| `cell_type` | 03/04 的 `ExperimentConfig`，切换 RNN/LSTM/GRU；05 的 B/C 共用门控单元 |
| `hidden_size` | 每个时间步隐藏状态的特征数 H |
| `num_layers` | 循环层堆叠层数 L，不是序列长度 T |
| `dropout` | 循环层之间的丢弃概率；只有一层时不生效 |
| `sequence_length` | 延迟回忆任务的时间步数；05 从转换后的数据推导 |
| `learning_rate`、`epochs`、`batch_size` | Adam 学习率、训练轮数和批量大小 |
| `gradient_clip` | 限制过大的参数梯度范数；不能保证解决长期依赖 |
| `seed` | 固定随机性；同一轮对照保持一致 |

默认模型单向、零初始状态、最后时刻读出，使用交叉熵与 Adam；普通 RNN 默认 tanh。前面延迟回忆模型对 LSTM 的遗忘门设置额外初始偏置，05 学生模型的具体初始化见其构造单元。不要把不同任务的成绩直接视为完全相同条件下的比较。

相同 H 的 RNN/LSTM/GRU 参数量不同；同一配置在不同长度上分别重新训练，属于任务长度比较，不等于同一个模型泛化到更长序列。不预设某个循环单元一定更好。

## 05：课后一周分层完成

课题是“让 RNN 用两种方式阅读服饰图片”。与 CNN 数据替换相比，增加序列组织、模型前向编程和空间还原检查。评分和正式提交形式按教师课堂说明，本项目不设置自动评分或准确率分数档位。

| 层次 | 需要学生完成的内容 | 主要证据 |
|---|---|---|
| 基础 | 读取图片、映射标签、按行构造序列、补全模型前向，训练 A | 图片行与时间步的对应、完整形状链、验证曲线 |
| 进阶 | 自己实现 4×4 空间分块与逆变换，完成 A/B/C 比较 | 坐标探针、非正方形检查、还原图、实际参数量和验证结果 |
| 挑战 | 自己增加全部时间步平均读出，与最后时刻读出比较 | 控制其他条件不变的实验与解释 |

基础逐行读取：`[B,1,28,28] → [B,28,28]`。进阶分块：`[B,1,28,28] → [B,49,16]`，49 个 4×4 块，每块 16 个像素。块按从左到右、从上到下排序，块内也逐行展开；两种表示都保留全部 784 个像素。

不能仅凭 reshape 后尺寸正确就认为转换正确。Notebook 用带坐标编号的小矩阵检查空间位置，并检查非正方形、不能整除的尺寸和转换还原。逆变换也由学生实现；两段错误代码可能互相抵消，因此还原一致并不能代替独立的位置检查。通用函数应按真实图片尺寸和类别数工作。

学生版保留数据路径/类别映射、批量读图、逐行转换、模型 forward、分块与还原等 TODO。只提供约定、分层提示和检查，不自动填答案。基础可独立完成；进入进阶与挑战前应按 Notebook 的开关和提示补齐相应 TODO。

### 三组受控实验

| 实验 | 表示方式 | 模型 |
|---|---|---|
| A | 逐行 | RNN |
| B | 逐行 | LSTM 或 GRU |
| C | 分块 | 与 B 相同 |

A→B 改循环单元；B→C 改序列组织。默认 CPU、H=32、1 层、每组 8 轮、batch=64、学习率 0.003、seed=42。三组保持相同图片、类别、划分和训练预算，记录实际参数量与耗时；分块同时改变 T/F 和输入参数量，不能把差异全部归因于记忆能力。挑战再比较同一表示下的两种读出。

图片包复用 [CNN 的 fashion_small.zip](../02_cnn_lab/data/fashion_small.zip)，包括 bag、sneaker、trousers 三类，每类 train/val/test 为 300/100/100 张。05 只负责解压课程文件，学生自行接入。不要删除 CNN 数据目录或把三个划分合并。数据来源与许可见 [CNN README](../02_cnn_lab/README.md) 和 [许可证](../02_cnn_lab/data/FASHION_MNIST_LICENSE.txt)，包内 `MANIFEST.json` 保存原始索引。

### 验证、最终测试和保存

1. 探索调用 `run_experiment(..., evaluate_test=False)`，只记录训练与验证；测试成绩为 `None`。
2. 用验证集比较并选型，分析验证错例；确定配置后不再调参，才手动开启最终测试。
3. `evaluate_final(selected)` 测试选定模型并缓存成绩。缓存仅对应首次测试的模型状态，不能修改模型后拿旧成绩当新成绩。
4. `export_experiments_csv` 导出配置、实际维度、表示/读出方式、参数量、耗时、验证结果及测试状态；未测试的成绩留空。输出写入本实验室的 `outputs/`，不随课程代码提交。

保留个人 Notebook、CSV、转换图、训练/状态图及错误分析。具体说明每个 T/F/H/K 的含义、改变了什么、哪些条件保持不变、证据支持什么结论。不同类别或不同划分的准确率不能放在同一排名中。

底层 `run_experiment` / `compare_cells` 的默认测试行为保留旧脚本兼容；本轮 Notebook 以及 quick_demo / compare 教学入口均显式关闭测试。编写自己的探索脚本时也应显式传 `evaluate_test=False`。
