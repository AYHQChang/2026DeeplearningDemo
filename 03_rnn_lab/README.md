# RNN实验室 文本情感分类三级实践

学生实际作业统一从[文本03](06_text_classification/03_自主修改与挑战.ipynb)开始。文本是主线，图片是选做迁移；原理00–04按需回看，不要求把全部Notebook都作为作业完成。

| 等级 | 提供与学生工作 | 默认行为 |
|---|---|---|
| 一级 运行与调参 | 提供完整普通RNN、train词表、训练和绘图；运行基线后改变一个参数，保留两组结果 | 可直接Run All，不需补代码 |
| 二级 补全LSTM | 模型框架与三处TODO：循环层构造、循环前向、有效句尾分类；先核对变长接口再训练 | RUN_LEVEL2=False，独立开启 |
| 三级 自主搭建GRU | 给模型接口、形状图、设计步骤和检查；允许nn.GRU，自己定义完整分类器并提交 | RUN_LEVEL3=False，不依赖二级 |

等级反映实现工作，不表示GRU理论上更复杂，也不要求准确率随等级提高。基础可以独立提交，不设自动评分。第一级集中修改learning_rate、hidden_size、epochs、batch_size、max_length等参数。完整LSTM/GRU在公共模块中标为教师参考；新学生入口不能用切换cell_type或省略model来代替实现。

## 实验规范

词表只由train建立，PAD=0、UNK=1。输入ID为[B,T]，Embedding为[B,T,E]，循环输出为[B,T,H]，有效句子表示为[B,H]，最终返回[B,2] logits。右侧PAD不属于真实句子；padding_idx不会让循环层自动跳过PAD。单层层间dropout不生效。同H不代表同参数量，比较时记录实际参数和耗时。

探索只用验证信息；RUN_FINAL_TEST=False，方案固定后再手动评价，不用测试选择参数。未测试的CSV字段留空。修改模型后旧测试缓存失效。概率未校准；隐藏状态及变化幅度是描述性观察，不是理解、注意力或因果解释。

图片逐行/分块顺序由读取规则规定，不是未来图片预测。文本有自然顺序，但本任务是情感分类，不是按日期采样的数值时间序列预测。
